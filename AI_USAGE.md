Our scan is the baseline one, so it only looks at the answers and doesn't really attack, which makes it safe on the live system. It found that the services were missing security headers, so we added them and made the scan fail if one ever goes missing. The website still has warnings because Azure Storage can't add headers, that would need Azure Front Door which costs money every month, and the website has no data or secrets. SAST and SCA run in CI before the build so they can stop a bad change, and DAST runs after the deploy because it needs the live app. |
